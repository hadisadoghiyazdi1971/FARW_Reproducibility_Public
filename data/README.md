# Experimental data boundary

The full set of 160 recording-level descriptor files and the raw acoustic recordings are **not bundled** in this public repository. The released selection bank stores observed-window indices, not the original signal windows or 40-descriptor matrices. The scenario manifests list recording identifiers but do not contain experimental signals.

No example descriptor files are fabricated or supplied. The included reference-result CSVs and Figure 6–7 scripts can be used without the excluded data; they do not provide an end-to-end rerun of RFE, window selection, or classification.
